# 学习引导的合并树搜索：最终验收结论

**完成了真实训练、冻结、树构造搜索、成本认证和公平对照。结果是：学习引导在 r≤16 的确认集上有小幅预算收益，但需要更多搜索时间，外推到 r=24/32 后落后于简单启发式；精确 DP 在当前范围内更快且总能给出最优树。没有证据支持继续用学习模型替代这个限定子问题的 DP。**

这里的“最优”仅指保持叶序、只合并相邻 runs 的满二叉树及指定预算 B，不是所有排序算法、实际比较次数或机器时间的最优性。

完整数表见 [findings.zh.md](findings.zh.md)，逐实例数据见 [paired.jsonl](paired.jsonl)，独立审计见 [saved-data-audit.json](saved-data-audit.json)、[final-review.json](final-review.json)，首次达到目标的分析见 [goal-analysis.json](goal-analysis.json)。

## 1. 模型确实参与了什么决策

训练了深度 2 和 4 的轻量 CART 回归树。标签来自训练向量的区间 DP：对每个区间和候选切点，计算其最优续接预算相对该区间最优值的额外预算，再除以区间重量。模型预测的是这个归一化 regret，**只用来排列切点，不是下界、正确性判断或剪枝依据**。

训练 132 个向量／72 个同源组，验证 44 个向量／24 组；共保存 34,980 条候选切点标签。标签构造约 70.2 ms，其中 DP 约 6.14 ms；两棵树训练合计约 1.092 s，均为本机 CPU。验证集选中深度 4、最小叶样本 16 的树，共 31 个节点，保存的格式化 JSON 为 4,215 字节。

实际树使用的分裂特征是：左右重量不平衡、切口相邻两段的重量占比、最大段占比及段数不平衡。没有读取元素排序答案、生成家族或测试最优解。训练端嵌套树与搜索端扁平模型的预测已交叉核对。

模型和参数于 **2026-09-08 21:08:12 UTC** 冻结，之后才生成 132 个确认向量／72 组、24 个段数外推向量／24 组，以及 6 个等长／空／单段结构诊断。没有根据最终结果调参或换模型。完整数据包括正反几何变化、随机段长、一个大段、多峰、交替长短、同源扰动以及真实列表扫描得到的 run 长度。

同源扰动留在原组，按除 gcd 后正反向最小向量核对缩放／反转泄漏。等长向量专门保留为结构诊断，不把其缩放克隆称为未见输入；确认集还核对了与本轮 smoke 数据的规范化向量无交集。独立生成输入仍可能偶然近似，不能声称杜绝所有结构相似性。

## 2. 同样搜索资源下，有没有改善

三种搜索共用同一初始解——旧 count 和 length 规则中预算较小者——以及状态、全部合法切点、左侧优先展开区间、去重、默认补全和终止规则。一次计数是弹出一个不同的部分树状态，包含完整状态；每个状态补全为一个可行树，再生成子状态。模型只改变切点优先级。**没有 beam 或分支定界，运行中可靠下界只有 0，也不因队列耗尽宣布 Lean 认证最优。**

### r=4/8/12/16：132 个确认输入

下表为 512 状态预算。时间先在每输入的三轮内取中位数，再报告跨输入中位数；不是各阶段重放相加。

| 方法 | 平均 B/OPT | 达到 OPT 的输入 | 规划／搜索中位时间 |
|---|---:|---:|---:|
| 按段数平衡 | 1.1355 | 23/132 | 0.0041 ms |
| 旧长度规则 | 1.0060 | 84/132 | 0.0097 ms |
| 精确 DP，含重建 | 1.0000 | 132/132 | 0.0377 ms |
| 固定展开顺序 | 1.0044 | 86/132 | 3.832 ms |
| 长度平衡优先搜索 | 1.0025 | 97/132 | 3.766 ms |
| 学习优先搜索 | 1.0013 | 102/132 | 4.893 ms |

学习使平均超额预算从约 **0.25% 降至 0.13%**，但不是逐实例支配：相对启发式 **11 个更好、13 个更差、108 个相同**；配对搜索时间比中位数为 **1.302**。32／128 状态的完整结果也保留，其中 128 状态为 12 胜、13 负、107 平，不能只挑有利预算展示。

在严格按轨迹截止的 2 ms 质量指标上，启发式／学习的平均 B/OPT 为 **1.0027／1.0014**；10 ms 为 **1.0015／1.0013**。说明在这批同分布输入上，优先级信息能带来一些实际搜索质量收益，但绝对空间很小。

### r=24/32：24 个独立外推输入

512 状态时启发式为 **1.0045、9.573 ms、5/24 达到 OPT**；学习为 **1.0067、11.245 ms、4/24 达到 OPT**。逐实例学习 **1 胜、12 负、11 平**。2 ms／10 ms 下学习也较差，没有把这批结果并入主确认集掩盖退化。

旧长度规则本身平均只比 OPT 高约 0.71%；该子问题不是没有选择空间，而是简单规则已经消除了大部分空间，学习还存在外推误排。

## 3. 达到相同质量，能否节省总搜索时间

需要区分“轨迹首次包含一个足够好的树”和“已经认证其最优且可以据此停止”。前者在本轮从保存轨迹事后计算，OPT／1.01 OPT 没有进入搜索器；后者还需要下界证书。

确认集有 84 个输入的共同初始解已经最优，不能把这些输入的微秒级首次命中归功于学习。其余 48 个初始非最优输入中，512 状态内启发式找到最优的为 **13 个**，学习为 **18 个**；仍分别有 **35、30 个**未达到。两者共同达到最优的 11 个输入上，学习／启发式首次命中时间比中位数为 **1.172**，没有总体提速证据。

对初始还未达到 1.01 OPT 的 19 个输入，启发式新增达到 8 个、学习新增达到 13 个；共同达到的 8 个输入上，时间比中位数为 **1.260**。不能比较两组不同的“仅成功样本”均值后宣布学习更快。所有未达到项保留，不填零或删掉。

墙钟请求在展开边界检查停止，因此不是硬实时算法。质量只取截止时间之前的事件，不计截止后的改善；实际请求超出仍全部保存，最大超出约 **35.0 ms**。可能包含单步工作及系统调度，未作排他性归因。不能把这个轨迹截止指标解释成保证准时返回。

## 4. 推理开销与精确 DP 的价值

512 状态确认请求中，学习特征与推理的跨输入中位累计时间分别约 **0.652、0.426 ms**，二者合计占实际搜索时间的逐输入比例中位数约 **22.7%**；外推约 **12.3%**。这些是在实际搜索内累计的诊断，包含相关计时器开销，不是从另一次重放任意相加。它们解释了一部分额外开销；访问不同结构的树也改变了补全和状态处理工作，不能把全部时间差归因于模型调用。

DP 没有被排除：同样用 Python、同一长度输入，直接测量完整求解与重建。确认集 DP 时间中位数 **0.0377 ms**，外推为 **0.4660 ms**。512 状态学习搜索／DP 的逐输入时间比中位数分别约 **77.8、25.9 倍**，且学习结果仍可能非最优。

单独 tracemalloc 重放测得 DP 峰值 Python 分配：确认中位 **10,342 字节**、最大 **23,748**；外推中位 **54,988**、最大 **82,780**。这是实际分配诊断，不是理论空间定理或进程 RSS；跟踪重放耗时没有混进主要 DP 时间。

本轮的完整最优性认证仍使用事后 DP 产生的 Bellman 下界表。因此学习不仅没有替代 DP，也没有消除认证最优所需的这部分离线工作。训练、参照、证书和排序内核各自记录，不能以搜索内暂时不调用 DP 为由声称整个认证流程不需要 DP。

## 5. 哪些保证经过 Lean 认证

通用证明和算法定义分别位于：

- [Model/MergeSearch.lean](../../../../LeanSort/Model/MergeSearch.lean)：满二叉树、叶序区间、预算和 Bellman 下界语义。
- [Algorithm/MergeSearch/Certificate.lean](../../../../LeanSort/Algorithm/MergeSearch/Certificate.lean)：可执行检查器、树实现及非法结构回退。
- [Verification/MergeSearch/Certificate.lean](../../../../LeanSort/Verification/MergeSearch/Certificate.lean)：检查器可靠性、叶序、正确性、比较界及含扫描的界。
- [Verification/MergeSearch/Checks.lean](../../../../LeanSort/Verification/MergeSearch/Checks.lean)：具体核内例子、预算与原 MergeTree 的一致性及最小预算迁移。

**已形式化证明：** 合法树不丢段、不重复、不改段内内容或叶序；其实现预算与原 `MergeTree.budget` 完全相等；合法有序 runs 的直接执行结果有序且保持排列，键比较数 ≤B；若从原列表扫描，界加入自然数截断的 n−1。非法树回退按段数平衡，仍正确。这里没有把验证 Worker 的离线输入核对或机器时间混进键比较定理。

对下界表逐区间检查所有合法切点的 Bellman 不等式，`lower_sound` 证明其根值 L 小于等于**任意**合法树的预算，而不只是已搜索的树。`checkOptimal_sound` 结合合法树的 U=L，推出规定空间内的最优性。这是可靠的最优性证书检查器；不是以有限测试代替通用最优性联系，也不是把经典 DP 递推当成创新。

**具体证据分层：** 493 棵不同的输入－树实例，包括所有返回树和中间改善树，通过了定理支持的 Lean 可执行检查器。r=0、1、4、8、12、16、24、32 各有一个代表实例另经 `by decide` 内核归约，生成具体最优性和候选合法性证明；还保留独立 pilot 证明。**不是所有 493 个条目都另存了独立内核归约证明项。** 编译执行检查器的信任边界与具体内核归约应当区分。

**仅检查／实测：** 预测质量、运行时间、分配量、Python 规划规则与 Lean 旧规则的一致性、全部具体特征和输出，以及编译产物的计时位置。没有证明 Python 搜索完整性、学习模型准确率、编译器正确性、机器时间或全局排序最优性。搜索队列耗尽也没有绕过证书获得最优标签。

还实际执行了 130 棵树，每棵三轮，所有输出及直接／参考比较数核对通过。40 个执行实例中，DP 树相对旧长度规则有 13 个比较更少、8 个更多、19 个相同，尽管 DP 的 B 从不更大。**更低的预算不是更少实际比较的充分条件。** 这些执行用于正确性及计数核对，计时次序未按正式内核性能研究设计，不据此声称排序加速。

## 7. 是否继续这个限定子问题

建议**停止以“学习替代小规模 B(T) 精确优化”为目标继续投入**。证据支持保留精确 DP 和可靠证书检查器，旧长度规则可提供很便宜的近优初始解。学习引导有小幅同分布质量收益，但没有稳定节省达到同样质量的总时间，且段数外推不佳。

这是对本轮表示、r 范围和成本目标的判断，不是否定一般的学习引导搜索。若以后加入 DP 无法直接分解的组合约束或多目标成本，可以重新提出独立研究问题；本轮不扩大范围，也不继续换模型直到跑赢。
